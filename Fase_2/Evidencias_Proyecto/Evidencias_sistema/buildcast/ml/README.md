# Machine Learning

Componente analítico de BuildCast para la estimación del plazo de construcción.

## Tecnologías

- Python
- pandas
- scikit-learn

## Responsabilidad

Esta carpeta contendrá:

- Preparación y limpieza de datos.
- Análisis exploratorio.
- Entrenamiento del modelo.
- Evaluación del modelo.
- Métricas de error.
- Versionado del modelo.
- Artefactos necesarios para su integración con FastAPI.

## Importante

Machine Learning se utilizará únicamente para estimar el plazo de construcción.

El costo de construcción será calculado mediante un motor determinista y no mediante Machine Learning.
